ADAPTATION

Big Cheese was rendered from the repository's native meshes, textures, and
pose. The original poster artwork supplied the layout and ray backdrop. A
source-based image-edit pass restored/recolored that backdrop for the brown
Bossbot theme. Final compositing preserves the source atlas slots, dimensions,
and model texture coordinates. Bossbot logos use the repository's own artwork.
For modern atlas recolors, the image edit establishes the brown color direction;
the final hue change is applied to the original pixels to retain exact UV edges.

No external visual assets were introduced. The package is a texture adaptation
of the credited source resources; it does not claim authorship of those source
assets. Original geometry and model files are not modified by this pack.

Assembly reference only:
https://github.com/RegDogg/TTR-Offline/blob/master/toontown/suit/Suit.py
This code was consulted for native Cog head/body assembly and medallion
placement. No visual assets were taken from that separate repository.

THIN-BORDER CORRECTION
The native Lawbot and Sellbot poster artwork boundaries were re-measured from
the original 3cmla_1 and 3cmla_4 atlases at the same source commit. The existing
Bossbot poster artwork is cropped and resampled into these native rectangles
without its redundant inset matte. No new character artwork is substituted.
